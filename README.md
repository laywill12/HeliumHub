# 【 Helium Hub ReadMe 】
Helium is a lightweight Roblox hub with a very good UI, designed for smooth performance and a clean user experience.

Helium is completely open source and free to use, giving people full access to its code and allowing people to explore, modify, or improve it.

Helium will receive updates, improvements, and new features over time to keep it updated.

That is all you need to know!
